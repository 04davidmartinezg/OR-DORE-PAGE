# OR DORÉ

Web estática local. Abre `index.html` en el navegador; no requiere instalación.

## Navegación
- Inicio: dos acciones, Explorar colección y Nosotros.
- Explorar colección abre `colecciones.html` en una pestaña nueva.
- Cada uno de los tres cuadros lleva a `catalogo.html?coleccion=gruta`, `cafe` o `amor`.
- El menú Conócenos contiene Nuestra empresa, Nuestra esencia y Galería.
- `galeria.html` dispone de seis espacios para fotografías.

## Contenido pendiente
Las imágenes se presentan como cuadros vacíos. Los catálogos tienen tres posiciones de muestra por colección; los productos reales, precios y descripciones aún no han sido proporcionados. La información de empresa es un borrador: sustituir por la historia y datos oficiales.

## Archivos
`Recursos/Css/styles.css` define la paleta y el diseño adaptable. `Recursos/JS/Script.js` controla la selección de catálogo y el menú móvil.

Paleta: #D4AF37, #F5E9D3, #D8C3A5, #4A2C20, #0B0B0B.

Los cambios se mantienen únicamente en el dispositivo, sin commit ni publicación.
